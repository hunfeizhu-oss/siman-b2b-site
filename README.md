# Sibuen Wooden Toy Export Website

英文主导、支持中文切换的木制玩具 B2B 外贸官网，基于 React + Vite 构建，可输出静态文件部署到任意服务器或静态托管平台。

## 本地预览

```bash
pnpm install
pnpm dev
```

## 生成部署文件

```bash
pnpm run build
```

构建产物位于 `dist/`，把 `dist/` 目录中的文件上传到服务器站点根目录即可访问。

## 页面与语言

- 默认语言为英文，点击顶部的 `中文` 可以即时切换；切换时会保留当前滚动位置和已填写的询盘内容。
- 页面包含产品分类、工厂故事、OEM/ODM 流程、企业价值、全球供货和询盘表单。
